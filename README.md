# 💥 HW5 - Regular Expressions #
This repositury contains three functions for amusing regular expressions usage. Demonstration of theese functions are provided in HW5_RegExp_Tasks.ipynb.
## Functions ##
`rename_files()` — renames or copies files according to a specified pattern.

`salt_translate()` — translates your text into the 'salt' language syllable by syllable. Be careful, as it can be too much fun...

`extract_chords()` — extracts unique chord names from a song lyrics file.
## Usage ##
Open HW5_RegExp_Tasks.ipynb to explore described functions in action.
